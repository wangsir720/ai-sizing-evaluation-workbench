## 3. 能力测算
### 3.1 向量规模
```text
总 token = 文档数 900 × 平均 1200 token = 1080000；切分步长 = 512 − 64 重叠 = 448；chunk 数 = 2411；向量 = 2411 × 1024 维 × 4 Byte = 0.01 GiB；含 1.3 索引开销后 = 0.02 GiB
```

### 3.2 Token 预算
```text
每次调用输入 = 问题 220 token + 检索命中 512 token（A-01 切分粒度）= 732 token；月输入 = 732 × 90000 次 = 65880000 token；月输出 = 180 × 90000 次 = 16200000 token
```
