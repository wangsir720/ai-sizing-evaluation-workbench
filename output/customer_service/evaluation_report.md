## 3. 能力测算
### 3.1 向量规模
```text
总 token = 文档数 1200 × 平均 1800 token = 2160000；切分步长 = 512 − 64 重叠 = 448；chunk 数 = 4822；向量 = 4822 × 1024 维 × 4 Byte = 0.02 GiB；含 1.3 索引开销后 = 0.04 GiB
```

### 3.2 Token 预算
```text
每次调用输入 = 问题 150 token + 检索命中 512 token（A-01 切分粒度）= 662 token；月输入 = 662 × 180000 次 = 119160000 token；月输出 = 120 × 180000 次 = 21600000 token
```

### 3.3 月度成本（按公开单价离线测算）
| 模型 | 混合输入价 | 混合输出价 | 月度成本(USD) | 年度成本(USD) | 相对最低价 |
|---|---|---|---|---|---|
| deepseek-v4-flash | 0.1950 | 0.7800 | 40.08 | 481.01 | 1.00× |
| deepseek-v4-pro | 0.8580 | 2.5740 | 157.84 | 1894.05 | 3.94× |

混合单价推导：
- **deepseek-v4-flash** 输入：谷时价 0.1500 × (1 + 峰时占比 30% × (倍率 2.0 − 1)) = 0.1950 美元/百万 token
- **deepseek-v4-pro** 输入：谷时价 0.6600 × (1 + 峰时占比 30% × (倍率 2.0 − 1)) = 0.8580 美元/百万 token

**未计入**：批量折扣、长上下文附加费、免费额度、企业协议价。
