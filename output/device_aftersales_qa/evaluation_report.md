## 3. 能力测算
### 3.1 向量规模
```text
总 token = 文档数 2400 × 平均 1500 token = 3600000；切分步长 = 512 − 64 重叠 = 448；chunk 数 = 8036；向量 = 8036 × 1024 维 × 4 Byte = 0.03 GiB；含 1.3 索引开销后 = 0.07 GiB
```

### 3.2 Token 预算
```text
每次调用输入 = 问题 160 token + 检索命中 512 token（A-01 切分粒度）= 672 token；月输入 = 672 × 260000 次 = 174720000 token；月输出 = 130 × 260000 次 = 33800000 token
```
